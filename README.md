## 🧩 概述

**Counter-Strike 2** 的**免费自定义观察者 HUD**，
专为 **OpenHUD v0.3.7** 构建和优化。
也可在 **Lexogrine HUD Manager** 中使用。

> ⚙️ 基于 [Lexogrine React HUD](https://github.com/lexogrine/cs2-react-hud)

## 🎨 功能特性

- 🟦🟥 蓝红配色方案
- 🎥 球队展示带有**动态透视效果**
- 💣 **C4 安放动画序列**
  _(注意：当前 OpenHUD 覆盖层尚不支持 `.webm` 动画)_
- 🔊 **残局 / 1v1 检测器** — 显示剩余选手并播放自定义音效
- 🖼️ 平滑的 CSS 过渡和高亮动画
